# 지표 정의

보고서에 쓰는 지표의 유일한 기준이다. 차트, 최신값 표, 수집 스크립트(`scripts/spec.py`가 이 파일을 읽는다) 모두 이 파일을 따른다.

## 열 설명

| 열 | 뜻 |
|---|---|
| id | 영문 소문자 식별자. 데이터와 스크립트에서 쓴다. 한 번 정하면 바꾸지 않는다. |
| 지표 | 차트 패널 제목과 최신값 표에 쓰는 이름 |
| 차트 설명 | 차트 패널 2행에 들어가는 고정 문구. 30자 안팎 |
| 단위 | 변환 후의 단위 |
| 주기 | 일 / 주 / 월 / 분기 / 연 / 수시. 수시는 정책금리처럼 바뀔 때만 값이 생기는 지표로, 계단 모양으로 그린다. |
| 변환 | `level` 원값 그대로, `yoy` 전년 동기 대비 %, `diff` 전기 대비 증감, `cumsum` 차트 기간 누적 |
| 기준선 | 차트에 회색 점선으로 그릴 값. 없으면 — |
| 출처 | 아래 표기법. 스크립트가 그대로 해석하므로 형식을 지킨다. |
| 비고 | 사람이 읽는 메모 (대체 출처, 정의 차이 등) |

## 출처 표기법

| 표기 | 뜻 |
|---|---|
| `fred:코드` | FRED. 키 없이 CSV로 받는다. |
| `yf:티커` | Yahoo Finance. 지표는 종가, 지수는 일봉(시가·고가·저가·종가·거래량) |
| `oecd-cli:국가` | OECD 경기선행지수 (진폭 조정) |
| `oecd-cpi:국가:품목` | OECD 소비자물가 전년비. 품목 `_T` 전체, `_TXCP01_NRG` 식료품·에너지 제외 |
| `ecb:데이터셋/키` | ECB Data Portal |
| `mof-jp:10Y` | 일본 재무성 국채 금리 |
| `hkma:hibor3m` | 홍콩금융관리국 HIBOR 3개월 |
| `ecos:통계표/주기/항목` | 한국은행 ECOS. 주기 `D` 일간, `M` 월간 (예: `817Y002/D/010200000` 국고채 3년) |
| `krx:이름` | KRX 정보데이터시스템 (pykrx). `kospi_pbr` KOSPI PBR, `kospi_foreign` KOSPI 외국인 순매수 |
| `estat:통계표/품목/지역/표장` | 일본 e-Stat (예: `0004052037/0161/00000/3` 전국 신선식품 제외 CPI 전년비) |
| `ak:이름` | AKShare. 이름별 수집 방법은 `scripts/sources.py` |
| `calc:식` | 다른 시계열로 계산. `{id}` 또는 `{출처}`를 쓴다. 식에서 처음 나오는 시계열의 날짜를 기준으로 계산하고, 나머지는 그 날짜 직전 값을 쓴다. |
| `manual` | 웹 검색으로 찾아 `data/manual.csv`에 수동 입력 |
| `none:사유` | 지금은 받지 않음. 차트에 `데이터 없음: 사유`로 표시 |

지수 표의 `거래량` 열은 주봉 차트에 쓰는 거래량의 출처다. `= 지수`는 지수와 같은 출처에서 받는다는 뜻이다.

지수 표의 `마감(KST)` 열은 그 시장의 종가가 확정되는 시각이다 (데이터 반영 여유 포함). 발행 시점에 아직 마감되지 않은 날의 봉은 쓰지 않는다. 미국·유럽은 다음 날 새벽에 마감되므로 `익일`을 붙인다.

한국은행 ECOS, KRX, 일본 e-Stat은 키나 회원 계정이 필요하다. 값은 `.env`에 둔다 (`ECOS_API_KEY`, `KRX_ID`, `KRX_PW`, `ESTAT_APP_ID`).
